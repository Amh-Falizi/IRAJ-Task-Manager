# 📝 Product Documentation & PRDs

The **Documents** module (`/documents`) provides a lightweight product documentation hub and wiki for writing PRDs, architectural decision records (ADRs), meeting notes, and API specs.

---

## 1. Creating and Categorizing Documents

1. Navigate to **Documents** (`/documents`).
2. Click **"New Document"**.
3. Fill in basic metadata:
   - **Document Title** (e.g. *Authentication Architecture Specification*).
   - **Category**: PRD, Architecture, Meeting Notes, User Guide, or RFC.
   - **Project Association**: Link to a specific project or keep global.
   - **Tags**: Comma-separated tags (e.g. `security`, `oauth`, `v2`).

---

## 2. Markdown Editor & Live Preview

The document editor features full **Markdown** rendering:
- **Formatting Toolbar**: Quick controls for bold, italics, headings, code blocks, bullet lists, tables, and blockquotes.
- **Side-by-Side Live Preview**: Toggle between raw Markdown edit mode, side-by-side preview mode, or rendered reading view.
- **Code Block Syntax Highlighting**: Automatic styling for TypeScript, JavaScript, SQL, Bash, and JSON code snippets.

---

## 3. Document Search & Export

- **Category & Project Filtering**: Filter documents by project or category using the sidebar menu.
- **Full-Text Search**: Search titles and document body content in real time.
- **Exporting Options**: Download any document as raw Markdown (`.md`) or printable HTML/PDF.
